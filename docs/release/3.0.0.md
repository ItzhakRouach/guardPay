# GuardPay 3.0.0

- **Released:** iOS, App Store — version `3.0.0`, build 30
- **Previous store version:** `2.0.5` (build 29, 2026-09-23, commit `60b766d`)
- **Commit range:** `60b766d..9e3d5ce` — 36 commits, 134 files, +10,541 / −2,660
- **OTA runtime lane:** `3.0.0` (`runtimeVersion.policy: "appVersion"`). The previous lane, `2.0.5`, received this same JS on 2026-09-27 as an OTA; it is tagged `v2.0.5` for hotfixes.

Everything in this release is JS-only. `app.json` did not change between 2.0.5 and this release except the version bump itself, and the only dependency change was swapping the Google Font packages for IBM Plex Sans Hebrew + Arabic (pure `.ttf`). A new binary is cut so the store listing, screenshots and release notes match what users are already running.

## Changelog

### Visual redesign (v3)
One typeface across the app — IBM Plex Sans Hebrew with IBM Plex Sans Arabic as its sibling, eight faces, replacing Manrope / Frank Ruhl Libre / Cormorant Garamond. New colour, shape and rhythm tokens in `lib/theme.js`; dark mode is a near-neutral ground rather than an inversion, so the app emits less light on a night shift. Shift rows are coloured by type. Nine legacy components removed (`ShiftCard`, `MonthSummary`, `MonthNetoCard`, `ProfileSummary`, `MonthPicker`, `Monogram`, `NoShiftsFound`, `AddShiftButton`, `LanguagesChange`, `MonthTotalCard`). WCAG AA is now enforced on every rendered token pair in both modes by `__tests__/contrast.test.js`.

### Month calendar
A month grid for Shifts with a calendar/list toggle that persists, and Add Shift opens on the day being viewed. New `components/shifts/MonthGrid.jsx` and `utils/monthGrid.js` — the calendar, the Shifts week grouping and the Overview chart now all read the same week arithmetic.

### Weekly overtime rules (opt-in)
A 42-hour weekly regular-hour cap, a configurable 8 / 8.6-hour daily norm, and an optional midnight split for shifts crossing midnight. Rules live in `users_prefs.overtime_rules`; week context is injected at write time and whole overlapping weeks are recomputed on a rule change. With rules off, `calculateShiftPay` is byte-identical to the historical function (test-locked in `__tests__/weeklyOt.test.js`). Adds guard (₪39.11) and supervisor (₪39.16) minimum-rate presets with a validity window.

### Compliance warnings
A new card flagging more than 12 hours in a day, more than 16 overtime hours in a week, and less than 36 hours of weekly rest. Informational only — it does not change pay.

### Undo a deleted shift
Deleting a shift is now reversible from the snackbar.

### Hebrew and Arabic
The app opens in the phone's language when it is one of `he` / `en` / `ar` (handling the legacy `iw` code), before the first screen renders. Layout direction is now set once at the app root as a Yoga `direction` style, replacing 52 hand-written `flexDirection` flips; text alignment and cross-axis alignment no longer double-flip. Vocabulary grew by 301 lines across all three locales.

### Reliability and performance
A shared shifts store with a single realtime subscription and one cached fetch per month; cached profile stats; an OTA update prompt and an error boundary; a service-unavailable screen instead of onboarding when Appwrite is unreachable; an overlay spinner on in-flow saves; the Add Shift form scrolls clear of the keyboard; shift type follows the hours entered.

### Not in this release
The חג-hours fix, sick days, vacation ranges and the paycheck PDF all shipped in 2.0.5 or earlier. The Appwrite keep-alive workflow and the 16 new test suites are not user-facing.
